## 经验反思 | Reflections (详见 2026-06-10-reflections.md)

1. **FeaturePrefs 文件不可修改** — 添加 KDoc/注解/import 均导致编译失败
2. **批量修改需渐进验证** — 先 1 个文件 → CI → 再 5 个 → CI → 全量
3. **工具参数名规范** — read_file(file_path,start_line,end_line), edit_file(file_path,old_text,new_text), execute(command,cwd,timeout)
4. **Python 多行需脚本文件** — cmd.exe 不支持 `python -c` 多行
5. **Git 压缩**: `git reset --soft <base>` → commit → `tag -f` → `push --force-with-lease`
6. **indexOf 扫描假阳性** — 正则漏掉同行 `.takeIf`，需手工抽样
7. **安全操作**: gradle/build 配置、文档、文件合并/import 清理
8. **危险操作**: 修改 FeaturePrefs*.kt / PlayerSettingsPart*.kt 结构
